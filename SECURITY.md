# Security and Intellectual Property Boundary

This repository is intentionally a PUBLIC VERIFICATION SURFACE.

It is not a complete publication of the proprietary ZT&SI implementation.

## Never Commit

- passwords
- API keys
- access tokens
- refresh tokens
- GitHub tokens
- cryptographic private keys
- signing secrets
- PFX or P12 containers
- private customer data
- private personal data
- private system prompts
- raw private conversations
- proprietary orchestration logic
- unpublished runtime source
- internal decision-engine implementation
- private datasets
- unrestricted recordings
- internal evidence packages

## Publication Rule

Publish enough to verify the record.

Do not publish material unnecessary for verification.

## Cryptographic Boundary

Publishing a cryptographic digest does not publish the private artifact represented by that digest.

## Intellectual Property

No license to unpublished or proprietary ZT&SI implementation material is granted merely by publication of this repository.

Evidence Before Narrative.
