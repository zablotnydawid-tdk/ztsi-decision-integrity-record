## 1. Architecture under evaluation

ZT&SI is evaluated as a single decision-governance stack rather than as
a claim that every named asset is a separate product.

`SOURCE → CLAIM → PROVENANCE → EPISTEMIC STATE → VALIDATION → DECISION ELIGIBILITY → DOMAIN LOGIC → CONTROLLED OUTPUT / ACTION → AUDIT`

The differentiating hypothesis is not "ZT&SI has a gate" or "ZT&SI uses
provenance." Those mechanisms have strong public analogues.

The narrower hypothesis is that ZT&SI moves the control boundary
upstream: it attempts to govern whether information supporting a
decision is epistemically admissible before governing the decision or
action itself.
