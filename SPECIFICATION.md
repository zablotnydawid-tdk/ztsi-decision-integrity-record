# ZT&SI Decision Integrity Record - Public Specification Surface

## Observable Decision Chain

SOURCE -> EVIDENCE -> CLAIM -> CLASSIFICATION -> GAP -> DECISION RULE -> VERDICT

## Public Classification Vocabulary

- FACT
- DECLARATION
- INFERENCE
- HYPOTHESIS
- UNKNOWN
- CONFLICT

## Integrity Rules

Unsupported inference must not silently become verified fact.

Material unresolved evidence gaps must remain explicit.

Corrections to provenance or evidence mapping must remain visible.

A canonical decision state may be cryptographically anchored.

- unpublished runtime source
- customer-specific logic
- private datasets
